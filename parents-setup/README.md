# הגדרת דוח ההורים (פעם אחת, כ-10 דקות)

הדוח שומר את ההתקדמות של הילדים בגיליון Google Sheets שלכם. האפליקציה של כל ילד שולחת אליו את הנתונים, ואפליקציית ההורים קוראת אותם.

## 1. יוצרים גיליון
1. נכנסים ל-[sheets.new](https://sheets.new) (עם חשבון הגוגל שלכם).
2. נותנים לגיליון שם, למשל "English Fun – דוח".

## 2. מדביקים את הקוד
1. בתפריט: **הרחבות (Extensions)** ← **Apps Script**.
2. מוחקים את כל מה שכתוב שם ומדביקים את כל התוכן של הקובץ [`Code.gs`](Code.gs).
3. בשורה `const PARENT_PIN = 'CHANGE-ME';` מחליפים את `CHANGE-ME` בקוד סודי שתבחרו (למשל `4821`). זה הקוד לכניסה לאפליקציית ההורים.
4. שומרים (סמל הדיסקט 💾).

## 3. מפרסמים
1. לוחצים **פריסה (Deploy)** ← **פריסה חדשה (New deployment)**.
2. ליד "בחירת סוג" לוחצים על גלגל השיניים ⚙️ ← **אפליקציית אינטרנט (Web app)**.
3. **הפעלה בתור (Execute as):** אני (Me).
4. **למי יש גישה (Who has access):** כל אחד (Anyone).
5. לוחצים **פריסה (Deploy)** ← **מתן גישה (Authorize access)** ← בוחרים את החשבון.
   - אם מופיע "Google hasn't verified this app": לוחצים **מתקדם (Advanced)** ← **מעבר ל-... (לא בטוח)**. זה הקוד שלכם, בגיליון שלכם.
6. מעתיקים את **כתובת אפליקציית האינטרנט** (מתחילה ב-`https://script.google.com/macros/s/...` ונגמרת ב-`/exec`).

## 4. שולחים את הכתובת
שולחים את הכתובת ל-Claude, והוא יחבר אותה לאפליקציות.

> **שינוי בקוד בעתיד:** אחרי עריכה ב-Apps Script צריך **פריסה ← ניהול פריסות ← עריכה ✏️ ← גרסה חדשה ← פריסה**, כדי שהכתובת תישאר אותה כתובת.
